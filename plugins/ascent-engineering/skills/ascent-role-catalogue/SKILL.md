# The role catalogue

`reference/full-manual.md` is a 6,600-line organization manual: one Chief, 23
department heads, 184 specialists, each with a charter, acceptance gates and a
dispatch prompt.

It is reference material, not a roster. Read the part you need.

## Why these are not 208 installed agents

Every installed agent's name and description is loaded into the main session on
every turn so that routing can happen. Two hundred and eight of those is a
permanent context tax paid on every message, and it makes routing *worse* rather
than better: the choice becomes one among two hundred near-synonymous
descriptions instead of six distinct ones.

The manual reaches the same conclusion in its own words - "a large on-demand
expertise catalogue, not 208 permanent employees and not 208 concurrent model
calls" - and sets a budget of six active subordinate agents.

So the six roles that match the work this repository actually generates are
installed as agents, and the remaining depth lives here, costing nothing until
it is opened.

## How to use it

**To brief an agent for work outside the six installed roles**, find the
specialist charter and paste the relevant part into the dispatch prompt. A
worker needs its charter, the shared rules, its ticket and the directly relevant
evidence - never the whole manual.

**To find a department**, the index is at the `## Department index` heading.
The 23 are: delivery · product · architecture · science · numerics · aerospace ·
drones · robotics · controls · mechanical · materials · electronics · thermal ·
UX · visual · charts · data · learning · QA · security · performance · platform ·
motion.

**To find one specialist**, search for its ID - `THERMAL-03`, `SECURITY-05` -
which anchors directly to its charter.

## What is already extracted

The manual's shared execution rules are the source of the
`ascent-operating-rules` skill, tightened and grounded in failures this
repository actually had. Prefer that skill; it is shorter, current, and
specific. Come here for domain charters the six agents do not cover.

## What the manual is not

Its own status note is worth repeating: it describes work to perform and
evidence to obtain. It is not a verified engineering library, not an audit of
the current checkout, and not authorization to change anything. Its description
of the project layout is a historical starting point - inspect the actual files
before acting on it.
